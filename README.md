# SANDI — склад и учёт домашнего текстиля

Локальное веб-приложение без сборки и дополнительных зависимостей.

## Запуск в VS Code

1. Откройте папку `D:\робота` в Visual Studio Code.
2. Запустите `index.html` в браузере. Для более надёжной работы `localStorage` можно использовать расширение Live Server.

Файлы проекта: `index.html`, `style.css`, `app.js`.

## Учёт и хранение

- Сохранённая накладная автоматически отражает полную сумму продажи в доходах и списывает товар со склада.
- Приход товара автоматически записывает закупочную сумму как расход и увеличивает складской остаток.
- Дополнительное начисление долга поставщику также попадает в расходы. Оплата поставщику уменьшает долг и не дублирует уже учтённую закупку.
- Оплаты клиента уменьшают долг; доход по накладной учитывается один раз, чтобы не задвоить продажу.
- В бухгалтерии доступны итоги за неделю, месяц, год и всё время. Прочие доходы и расходы добавляются вручную.
- Фото товара необязательно. Перед сохранением изображение уменьшается; данные остаются в `localStorage` этого браузера и устройства.
- В накладной можно указать процент скидки отдельно для каждой позиции. Скидка пересчитывает сумму позиции, итог, долг клиента и доход в бухгалтерии; склад списывает прежнее количество товара.
- В электронной и печатной накладной цены, суммы и итог показываются в гривнах и долларах по курсу на дату оформления. В накладной не печатаются поставщик и строки подписей.
- В кабинете «Способы отправки» можно вести варианты доставки. В печатной накладной указаны выбранный способ и сохранённый курс доллара; в заголовке остаются номер заказа и дата без времени.
- В карточке клиента можно хранить заметки о заказах и истории общения.
- Кабинет «Заметки» хранит рабочие записи и прикреплённые фотографии в localStorage.
- В поставке можно задать процент скидки: в расходы и долг поставщику записывается сумма после скидки.
- При расчётах с поставщиком можно ввести сумму в гривне или долларах. Доллары пересчитываются по курсу из кабинета директора; в балансе и бухгалтерии хранится гривневый эквивалент.
- Товары и поставщиков можно редактировать. Неиспользуемые записи удаляются; если есть история операций, карточка уходит в архив, чтобы сохранить складские движения и расчёты.

Очистка данных сайта в браузере удалит записи. Для доступа нескольких сотрудников с разных устройств понадобится серверная база данных и авторизация.
